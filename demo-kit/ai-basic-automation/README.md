# AI 쉽고 재밌게 활용하기: 기초편 — 데모 팩

> 92년생 직장인 김민지 페르소나의 5단계 흐름을 본인 직군으로 치환해 따라가며, 마지막에 HTML 한 페이지 대시보드를 만드는 데모 팩.

이 문서는 두 가지 용도로 작성됐습니다.
- **AI가 읽는 마스터**: `README.md` (본 파일). ChatGPT/Claude에게 통째 첨부해 "내 클래스 자료입니다"로 시작 가능
- **사람이 보는 사본**: `USAGE.pdf` — 인쇄·휴대용

---

## 데모 팩 구성

```
demo-pack/
├── README.md                       (AI/사람 마스터 사용법)
├── USAGE.pdf                       (사람 인쇄용 사본, README.md 변환)
└── samples/
    ├── step2-card-statement.csv    (실습 2 카드 사용 내역)
    ├── step2-utility-bill.md       (실습 2 전기세 고지서 텍스트)
    ├── step3-search-targets.md     (실습 3 검색 시나리오)
    └── step5-dashboard-starter.html (실습 5 시작점 — 최소 골격)
```

## 페르소나 — 김민지 (예시 주인공)

- 1992년생 마케터 (중견기업 8년차, 33세)
- 서울 마포구 1인 가구
- 월 고정 지출: 월세 80만 · 관리비 12만 · 전기·가스 평균 5만 · 건보료 18만 · 적금 30만 · 넷플릭스 1.7만
- 일상 고민: 월급 어디로 새는지 / 청약 일정 매번 검색 / 투자 뉴스 따라잡기 어려움 / 일정 흩어짐
- 욕구: 모든 게 한 화면에 모이는 "일상 사령탑"

**김민지는 예시.** 본인 직군으로 치환해서 따라갑니다.

### 직군 치환표

| 직군 | 1단계 체크리스트 | 2단계 첨부 | 3단계 최신 정보 | 4단계 결과물 | 5단계 대시보드 위젯 |
|------|----------------|----------|----------------|------------|--------------------|
| 직장인 | 청약·세금 신고·연차 | 카드 사용·전기세 | 청약 일정·코스피 | 지출 인포그래픽 | 고정지출·루틴·캘린더 |
| 자영업 | 부가세·재고·예약 | 매출 캡처·발주표 | 마트 할인·세무 일정 | 매출 인포그래픽 | 매출·발주·예약 |
| 주부 | 생활비·학원·병원 | 가계부·관리비 | 학원 등록·약국 | 가계 인포그래픽 | 가계·아이 일정 |
| 학생 | 시험·과제·동아리 | 시간표·성적표 | 학사·시험 일정 | 학습 인포그래픽 | 시간표·과제·캘린더 |

## 실습 1 — 말 걸어보기 (체크리스트 요청)

**도구**: ChatGPT / Claude / Gemini 중 본인 도구.

**프롬프트 1-1 (시작)**

```text
나는 [본인 나이/직군/거주]야.
이번 분기에 내가 챙겨야 할 일들을
카테고리(돈·일정·서류·건강)로 나눠서
체크리스트로 정리해줘. 각 카테고리당 5개 이내로.
```

**김민지 예시**:
```text
나는 1992년생 마케터고 서울 마포에서 혼자 살아.
이번 분기에 내가 챙겨야 할 일들을
카테고리(돈·일정·서류·건강)로 나눠서
체크리스트로 정리해줘. 각 카테고리당 5개 이내로.
```

**프롬프트 1-2 (재질문)**

```text
좋아. 각 항목 옆에 "오늘 시작할 수 있는 첫 행동"을 한 줄씩 추가해줘.
애매한 건 "사람 검토 필요"라고 표시해줘.
```

> ✅ 단계 1은 본인 상황 맞춤 체크리스트만 받습니다. 최신 일정·시세 정보(청약 신규 공고·헤드라인 등)는 단계 3에서.

## 실습 2 — 사진·파일 같이 보내기

**도구**: 같은 본인 도구 (ChatGPT/Claude/Gemini 모두 첨부 지원).

**첨부 옵션**:

- **옵션 A** — 강사 배포 CSV: `samples/step2-card-statement.csv` (8건 가상 카드 사용 내역)
- **옵션 B** — 강사 배포 텍스트 고지서: `samples/step2-utility-bill.md` (전기세·가스비 가상 고지서)
- **옵션 C** — 본인 데이터: 카드 사용 내역 캡처 / 가계부 / 캘린더 스크린샷 (민감정보 익명화 필수)

**프롬프트 2**

```text
[준비한 파일 첨부]
이 데이터를 보고:
1. 어디에 가장 많이 썼는지 (또는 어떤 패턴이 있는지)
2. 다음 달/주에 줄이거나 챙기면 좋을 항목 3개

민감 정보가 보이면 익명화해서 답해줘.
```

비교 포인트: 실습 1(텍스트) vs 실습 2(파일) — 어느 게 더 편한가? 옆사람과 한 줄 공유.

## 실습 3 — 도구 사용하기 (검색 + 스케쥴 맛보기)

### 3-1. 웹 검색

**도구·켜는 법**:
- ChatGPT: 입력창 위 "검색" 또는 지구 아이콘 클릭
- Claude: "최신 정보 검색해줘" 명시 또는 자동 웹 검색
- Gemini: 기본 Google 검색 연동
- Perplexity: 가입 없이 검색 답변 (`perplexity.ai`)

**프롬프트 3 (학생 시도)**

검색 시나리오는 `samples/step3-search-targets.md` 참조. 예시:

```text
내 체크리스트 중 외부 정보가 필요한 게 있어.
"[본인 항목]"에 대해 최신 정보를 검색해서 알려줘.

- 출처도 같이 (URL)
- 확실하지 않으면 "확인 필요" 표시
```

직군별 예시:
- 직장인: "이번 주 청년 무주택자 청약 일정"
- 자영업: "이번 주 대형마트 할인 정보"
- 주부: "다음 주 동네 학원 등록 마감"
- 학생: "이번 학기 학사 일정"

**체크**: 출처 1개 이상 직접 클릭해 확인.

### 3-2. 스케쥴 / Tasks (강사 시연 위주)

ChatGPT Tasks (유료) 또는 비슷한 자동 발송:
- "매일 아침 9시 코스피·코스닥 헤드라인 5개 보내줘"
- "매주 금요일 청년 청약 신규 공고 알려줘"

> 💡 무료 사용자는 강사 시연만 보고 "이런 도구도 있구나" 인식. 단계 5 대시보드에서 비슷한 위젯으로 자체 구현.

## 실습 4 — 결과물 만들기 (대표 1개 + 메뉴 시연)

### 4-1. 대표 실습 — 인포그래픽 1장 (모두 시도)

**도구**: ChatGPT 이미지 생성

**프롬프트 4**

```text
방금 실습 2에서 분석한 [지출 / 매출 / 학습] 결과로
정사각형 인포그래픽 카드 1장 그려줘.

- SNS 공유용
- 친근하고 밝은 느낌
- 핵심 숫자 3개 강조
```

캡처해서 옆사람에게 보여주기.

### 4-2. 강사 메뉴 시연 (각 30초)

- **PDF 요약**: Claude Artifact 또는 ChatGPT Canvas → 마크다운 → PDF 다운로드
- **PT 슬라이드**: Claude로 Marp 마크다운 → 슬라이드 변환
- **1분 영상 시나리오**: 텍스트 시나리오 + 자막

본인이 흥미 있는 형식 1개 메모.

## 실습 5 — 나만의 대시보드 만들기 ⭐

### 5-1. 도구 선택

| 옵션 | 가입 도구 | 진입 |
|------|---------|------|
| **Primary** — Claude Artifact | Claude.ai | 우측 패널에 즉시 렌더 |
| **Primary** — ChatGPT Canvas | ChatGPT | 미리보기 화면에 렌더 |
| Secondary — 로컬 dashboard.html | 위 둘 중 하나 | 결과를 HTML 파일로 저장 → 더블클릭 |
| **Bonus** — Claude Code / Cursor / VS Code | (희망자만) | 보조강사 1:1, localhost 실행 |

### 5-2. 프롬프트 5

```text
나만의 일상 사령탑 대시보드를 HTML 한 페이지로 만들어줘.
오른쪽 화면(Claude Artifact) 또는 미리보기 화면(ChatGPT Canvas)에 바로 보이게.

상단: 내 이름 [본인 이름]과 이번 달 (예: 2026년 5월)

좌측 상단 — 고정 지출 표
- 월세 80만 (매월 1일)
- 관리비 12만 (5일)
- 전기·가스 평균 5만 (5~10일)
- 건보료 18만 (10일)
- 넷플릭스 1.7만 (12일)
- 적금 30만 (25일)
각 행: 이름·금액·결제일

우측 상단 — 변동 지출 입력 (input 3칸)
이번 달 전기세 / 이번 달 가스비 / 건보료 추가

좌측 하단 — 오늘의 루틴 투두 (체크박스 5개)
- 회의록 정리
- 고객 답장 5건
- 주간 보고서
- SNS 콘텐츠 1건
- 운동 30분
+ "추가" 버튼 (간단하게)

우측 하단 — 통합 캘린더 미니뷰
이번 달 7×5 그리드, 고정 지출 결제일에 점 표시

톤: 다크 배경 + 블루 글로우 (SemiClass 스타일)
데이터는 하드코딩 OK
```

### 5-3. 시작점 옵션

`samples/step5-dashboard-starter.html`에 최소 골격이 있습니다. AI에게 "이 파일을 시작점으로 채워줘"로 요청 가능.

### 5-4. 완료 기준 (현실적)

- ☐ 화면에 대시보드 1페이지 표시됨
- ☐ 투두 체크박스 1개 이상 클릭 → 시각 반응 동작
- ☐ 캡처 1장 (다운로드 또는 화면 캡처)
- ☐ (Bonus) 변동 지출 입력 → 표 갱신 동작

옆사람에게 30초 보여주기.

### 5-5. Bonus — 로컬·배포

- Claude Code/Cursor/VS Code로 `dashboard.html` 저장 → 브라우저로 열기
- 더 나아가 Vercel 배포 (5분) + Supabase 테이블 1개 연동 (10분)
- → 다음 클래스 **바이브코딩 × 기초** ⭐ 에서 본격적으로 다룸

## 사람 검토 체크리스트

AI 결과를 그대로 믿지 말고:

- [ ] 실제 마감·금액이 맞는가?
- [ ] 검색 결과의 출처는 신뢰할 만한가?
- [ ] 민감 정보가 들어가 있지 않은가?
- [ ] AI가 사실을 지어내지 않았는가?
- [ ] 최종 결정·전송은 내가 하는가?

## 후속 클래스 연결

오늘 만든 대시보드를 더 키우고 싶다면:

- AI 도구·기능 더 다양하게 → **AI 툴 활용 × 초급**
- 매일 자동 실행되는 작업 (Tasks·MCP) → **에이전틱 AI × 기초**
- 오늘 만든 대시보드를 본격 웹·앱 + 배포 → **바이브코딩 × 기초** ⭐
- Sheet·Notion·Zapier 실제 연결 → **AX 클래스**
