# 단계 4 결과물 4종 명세

> 단계 4 "결과물 만들기"에서 만들 결과물 4종의 형식·톤·완성 기준. AI가 같은 Chat Project [파일] 영역의 02-campaign-analysis.md를 참고해 본 명세대로 결과물을 우측 Artifact 패널에 띄웁니다.

## 1. 캠페인 인포그래픽 1장 (대표 결과물)

- 형식: HTML/SVG 정사각형 카드 1장 (Artifact 패널)
- 헤더: "Hello May 회고 · 2026-05"
- 핵심 숫자 3개 크게: CTR 2.1% / 전환 1,400건 / ROAS 4.3x
- 부가: 매출 5,160만 원(+14.7% YoY), 인사이트 1줄, 다음 액션 1줄, 워터마크 "Marketing Team"
- 스타일: 다크 톤(#1D242B) + 블루(#068FFF)·옐로우(#FFD166), 친근하지만 정돈된 임원 보고용

### 변주 — 동료 공유 톤
- 같은 데이터, 일러스트 느낌, 이모지 3개, "수고했어요!" 메시지 1줄, 슬랙 공유 카드 톤.

## 2. 주간 보고서 PDF

- 형식: 마크다운 1페이지 → 브라우저 PDF 인쇄용
- 구성:
  1. 캠페인 진행 현황 (Hello May 종료 + 다음 캠페인 D-day)
  2. 콘텐츠 진행 (이번 주 SNS 5건 상태)
  3. 다음 주 할 일 3개 (이번 주 회의록에서 추출)
  4. 위험 1개 + 대응 방안
- 길이: 1페이지 안. 표는 2개 이하.

## 3. SNS 콘텐츠 카드 3장 (시리즈)

- 형식: HTML 카드 3장 (런칭/중간/마감 톤 통일)
- 각 카드 본문:
  - 1장: 런칭 — "Hello May 시작! 봄 신상 만나러 가요"
  - 2장: 중간 — "벌써 D-7. 인기 컬러 사이즈 빠르게 매진 중"
  - 3장: 마감 — "오늘 자정 종료. 마지막 5% 추가 할인"
- 스타일: 정사각형 1080x1080, 다크 톤 + 블루 글로우 일관

## 4. 회의록 요약 PT

- 형식: Marp 마크다운 → 5장 슬라이드
- 구성:
  1. 회의 제목·날짜·참석자
  2. 핵심 의사결정 3개
  3. 액션 아이템 5개 (담당자·기한)
  4. 위험·차질 2개
  5. 다음 회의 일정

## 결과물 검증 체크리스트 (AI 출력 후 자동 확인)

- [ ] 실제 마감·금액·KPI 숫자가 02-campaign-analysis.md와 일치하는가
- [ ] 민감 정보(고객명·실제 KPI·계좌)가 포함되지 않았는가
- [ ] AI가 사실을 지어내지 않았는가 (출처 없는 숫자는 "추정" 표시)
- [ ] 외부 발송·임원 보고 전 사람 검토 필요한 부분이 명시되어 있는가
