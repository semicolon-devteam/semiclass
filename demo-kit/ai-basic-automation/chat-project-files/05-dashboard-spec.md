> 단계 5 "나만의 대시보드 만들기" 명세. 같은 Project [파일] 영역의 01~04 산출물을 참고해 **단일 HTML 한 페이지를 Artifact로** 띄웁니다. `step5-dashboard-starter-localStorage.html`을 시작점으로 쓰면 localStorage 누적이 이미 들어 있습니다. **무료 플랜 포함 전 플랜 동일.**

## 영속성 — 다운로드 → 바탕화면 → 매일 누적

> Artifact **화면 안에서는** sandbox 때문에 localStorage가 막힙니다. **코드를 다운로드해 본인 PC에서 열면** sandbox 밖이라 정상 작동 — 무료로도 매일 누적됩니다.

1. Artifact 우측 하단 **`</> 코드` → 다운로드** (무료 포함 전 플랜 동일)
2. 파일명 **`점검판.html`**, 저장 위치 **바탕화면**
3. 그 파일을 **더블클릭** — 브라우저가 열리고 끝 (인터넷·설치·계정 X)
4. 투두 체크·변동 지출 입력 → **새로고침해도 누적** (localStorage)
5. 더 손보고 싶으면 오늘 쓴 **같은 Chat Project를 다시 열어** "지난번 점검판에 위젯 하나 더"로 이어가기

> 코드가 끊기면: "코드가 중간에 끊겼어. 마지막으로 출력한 줄부터 이어서 나머지만 출력해줘."
> 막혔을 때 안전망: `samples/step5-dashboard-starter-localStorage.html` 그대로 다운로드 → 바탕화면 → 더블클릭하면 완성본이 이미 매일 누적 동작.
