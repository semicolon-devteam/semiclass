# 내 케이스로 갈아끼우기 — 템플릿 + 가이드

> 데모 팩의 `cowork-folder/`는 김민지씨(33세 마케터) 시나리오로 모든 자료가 채워져 있습니다. 이 폴더(`your-template/`)는 **본인 직무·연차·가구에 맞게 갈아끼울 때 쓰는 빈 양식**입니다. 5분이면 본인 페르소나로 단계 4·5를 다시 돌릴 수 있어요.

## 직군별 변주 예시 (페르소나 첫 두 줄)

```text
# 영업 5년차
- 1994년생 B2B 영업 (중견기업 5년차, 32세)
- 분당 거주, 부부+1, 강아지 한 마리

# 개발 1년차
- 1998년생 백엔드 개발자 (스타트업 1년차, 28세)
- 강남 1인가구, 회사 도보 15분

# 기획 8년차
- 1991년생 서비스 기획자 (이커머스 8년차, 34세)
- 마포 부부+0, 자취 5년차

# HR 3년차
- 1996년생 HR 매니저 (200명 규모 회사, 30세)
- 송파 1인가구, 회사 통근 50분
```

답변 톤·정책·자주 쓰는 결과물 영역은 김민지씨 템플릿 그대로 두거나, 본인 업무 결과물에 맞게 한 줄씩만 바꾸면 됩니다.

## 사용 순서

1. 본 폴더(`your-template/`)를 통째로 복사해서 본인 PC의 편한 위치에 둠 (예: `~/Documents/my-cowork-folder/`)
2. `CLAUDE.md`와 `00-내-프로필.md`에서 첫 두 줄(직무·가구) 바꾸기
3. `02-work-data-template.md`에 본인 업무 데이터 1건을 양식대로 채우기 (실적 표·KPI·날짜 등)
4. `03-search-targets-template.md`에 본인이 매번 직접 찾는 외부 정보 5종 적기
5. `04-deliverable-brief.md`에서 4종 결과물 중 본인이 가장 자주 만드는 1종의 데이터·헤더·스타일 변주
6. Cowork → 새 작업 → 위 폴더 연결 → 단계 4·5 실습 그대로 따라가기

## 자주 묻는 질문

**Q. 김민지 데이터를 다 지워야 하나요?**
A. 본인이 정말 쓸 항목만 갈아끼우고 나머지는 그대로 둬도 OK. AI는 본인 정보가 있는 곳을 우선 참조하고, 빈 자리는 김민지 예시로 채워서 결과물을 만들어 줍니다 — 그 결과물이 본인 톤에 안 맞으면 그때 그 줄만 바꾸세요.

**Q. 단계 1~3은 김민지로 따라가고 단계 4~5만 본인 데이터로 해도 되나요?**
A. 가장 추천하는 흐름입니다. 본편 시간 안에는 김민지로 빠르게 1~3 체험한 뒤, 본 폴더를 미리 채워두고 단계 4·5만 본인 데이터로 갈아끼우면 됩니다. 강사·보조강사가 옆에서 도와드립니다.

**Q. 본인 자료가 회사 내부 정보라 그대로 못 올리는데?**
A. **민감정보 가명·둥근 숫자 원칙**으로 처리하세요. 캠페인명·고객명·실제 KPI는 "A 캠페인 / X사 / 1,000회" 형태로 — 결과물 톤은 그대로 유지됩니다. 본인 검토 후 외부 발송 시 실제 숫자로 갈아끼우면 됩니다.

**Q. 결과물 4종 중 본인이 안 쓰는 형식이 있는데?**
A. `04-deliverable-brief.md`에서 안 쓰는 섹션은 비워 두거나 본인이 자주 만드는 다른 형식(예: 영업 제안서 1페이지·개발 릴리즈 노트·기획 PRD 표지·HR 채용 공고 카드)으로 갈아끼우세요. AI는 명세에 적힌 대로 만들어 줍니다.
