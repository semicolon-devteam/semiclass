# CLAUDE.md — 폴더 자동 컨텍스트 (본인 케이스용 템플릿)

> Cowork이 폴더 열 때 가장 먼저 읽는 자동 지침 파일입니다. **아래 사용자 페르소나 영역만 본인에 맞게 바꿔주세요.** 답변 톤·자주 쓰는 결과물 영역은 그대로 둬도 무난합니다.

## 이 폴더가 무엇인지

SemiClass "AI 쉽고 재밌게 활용하기: 기초편"의 실습 4·5 본인 케이스 자료실입니다. 본인이 직접 작성한 산출물·체크리스트·결과물 명세가 모여 있어, Cowork으로 폴더 연결만 하면 본인 페르소나로 단계 4·5를 진행할 수 있습니다.

## 사용자 페르소나 — 항상 적용 (✏️ 여기만 바꾸세요)

- **[YYYY년생 직무 직책]** ([회사 규모/연차], [현재 나이]세)
- [거주 지역 가구 구성, 동거 가족·반려동물]
- [재무 상황: 청약·적금·CMA·대출 등]
- [건강·생활 한 줄]
- 업무 루틴: [본인 업무 핵심 5종]

### 변주 예시

```text
# 영업 5년차 — 1994년생, B2B 중견기업, 분당 부부+1
# 개발 1년차 — 1998년생, 스타트업 백엔드, 강남 1인가구
# 기획 8년차 — 1991년생, 이커머스 PO, 마포 부부+0
# HR 3년차 — 1996년생, 200명 규모, 송파 1인가구
```

## 답변 톤·정책 (기본값, 그대로 둬도 OK)

- 답변은 **한국어 친근체** (반말이 자연스러운 일상 영역) 또는 정돈된 존댓말(임원 보고·외부 발송)을 맥락에 맞게
- 숫자에 출처가 없으면 **"추정"** 표시
- 민감정보(고객명·실제 KPI·계좌)는 가명·둥근 숫자로 바꿔서 처리
- 외부 발송·임원 보고용 결과는 **"사람 검토 필요"** 표시

## 자주 쓰는 결과물 (✏️ 본인 1순위 결과물 1종만 정확히, 나머지는 옵션)

| 결과물 | 명세 위치 |
|--------|----------|
| [본인 1순위 결과물 — 예: 영업 제안서 1페이지] | `04-deliverable-brief.md` "1번" |
| [옵션 — 주간 보고서 / 릴리즈 노트 / 회의록 PT 중 1] | `04-deliverable-brief.md` "2번" |
| [옵션 — SNS 카드 / 채용 공고 카드 / 기획안 표지 중 1] | `04-deliverable-brief.md` "3번" |
| [옵션 — 회의록 요약 PT / 1분 영상 시나리오 중 1] | `04-deliverable-brief.md` "4번" |
| [본인 통합 점검판 6 위젯] | `05-dashboard-spec.md` 전체 |

## Scheduled 작업 안내

매일·매주 자동 갱신을 원하면 `05-dashboard-spec.md`의 Scheduled 섹션에 본인 직무에 맞는 cron 작업을 적어두세요. AI가 폴더를 열 때 그 명세 그대로 Cowork 좌측 사이드바 Scheduled에 등록할 수 있게 안내합니다.
