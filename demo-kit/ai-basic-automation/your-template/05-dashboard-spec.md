# 내 점검판 명세 — 본인 케이스 (4 위젯 본편 / 6 위젯 보너스)

> 단계 5 "통합 대시보드"의 본인 화면 명세. 같은 Chat Project [파일] 영역의 01~04 본인 산출물을 참고해 **단일 HTML 한 페이지를 Artifact로** 띄웁니다. **위젯 4개만 채우면 본편 완료**(2개 더 채우면 6 위젯 = 보너스). 김민지 마케터의 캠페인/SNS/KPI는 본인 직무에 맞는 위젯으로 갈아끼우세요. `samples/step5-dashboard-starter-localStorage.html`을 시작점으로 쓰면 localStorage 누적이 이미 들어 있습니다. **무료 플랜 포함 전 플랜 동일.**

## 통합 원칙

- 단일 HTML 한 페이지, **본편 위젯 4개**(보너스로 6개까지)
- 데이터는 01·02·03·04 본인 [파일] 영역 자료에서 자동 추출
- 만든 뒤 **코드를 다운로드해 바탕화면 `점검판.html`로 저장 → 더블클릭**하면, sandbox 밖이라 새로고침해도 입력·체크가 누적됩니다 (localStorage, 무료)

## 헤더

- 제목: "[본인 이름·직무] 점검판"
- 부제: "[본인이 매일 보고 싶은 영역 3개를 ·로 연결]"
- 우측 상단: ⭐ 오늘의 완성 배지

## 위젯 — ✏️ 본인 직무로 갈아끼우기 (1·3·5·6 본편 / 2·4 보너스)

### 위젯 1 — 본인 직무 진행 (좌상단) · 본편
직군별 예시:
- 영업: 진행 중인 딜 3개 — 단계·예상 마감·예상 ARR
- 개발: 현재 스프린트 진행 — 백로그·진행 중·완료
- 기획: 현재 분기 핵심 KPI 3개 — 목표·실적·달성률
- HR: 채용 진행 — 포지션·후보군·다음 액션

### 위젯 2 — 본인 콘텐츠 캘린더 (중상단) · 보너스
직군별 예시:
- 영업: 이번 주 미팅·콜·제안서 발송 일정
- 개발: 이번 주 PR 리뷰·배포·온콜 일정
- 기획: 이번 주 인터뷰·기획안 발행·실험 시작 일정
- HR: 이번 주 면접·온보딩·이직 1on1 일정

### 위젯 3 — 본인 KPI 트래커 (우상단) · 본편
- KPI 4개 진행 바, 목표/현재/달성률
- 본인 직무 핵심 지표 (02-work-data-template에서 자동)

### 위젯 4 — 고정 지출 + 변동 입력 (좌하단) · 보너스
- 본인 월 고정비 (월세/대출/구독 등)
- 변동 입력 3칸 (이번 달 전기·가스·수도 등)

### 위젯 5 — 오늘의 루틴 (중하단) · 본편
- 본인 직무 + 생활 루틴 5개 체크박스
- 01-domain-checklist에서 자동

### 위젯 6 — 통합 캘린더 (우하단) · 본편
- 본인 이번 달 7×5 그리드
- 결제일/마감일/세미나/세금 점 표시
- 03-search-targets-template + 01에서 자동

## 스타일

- 다크 (#1D242B) + 본인 브랜드 컬러
- Pretendard / 시스템 sans-serif
- 위젯을 3×2 그리드(본편 4개 + 보너스 2개), 위젯 간 12~16px gap

## 영속성 — 다운로드 → 바탕화면 → 매일 누적

> Artifact **화면 안에서는** sandbox 때문에 localStorage가 막힙니다. **코드를 다운로드해 본인 PC에서 열면** sandbox 밖이라 정상 작동 — 무료로도 매일 누적됩니다.

1. Artifact 우측 하단 **`</> 코드` → 다운로드**
2. 파일명 **`점검판.html`**, 저장 위치 **바탕화면**
3. 그 파일을 **더블클릭** — 브라우저가 열리고 끝 (인터넷·설치·계정 X)
4. 입력·체크 → **새로고침해도 누적** (localStorage)
5. 막혔을 때 안전망: `samples/step5-dashboard-starter-localStorage.html` 그대로 다운로드 → 바탕화면 → 더블클릭

## 완료 기준 (본편)

- ☐ Artifact에 대시보드 1페이지 표시 (위젯 **4개 이상**이면 성공, 6개는 보너스)
- ☐ 변동 입력 1개 이상 → 화면 갱신
- ☐ 투두 1개 이상 체크 → 시각 반응
- ☐ 코드 다운로드 1회 → 바탕화면 `점검판.html` 실행 확인

매일/매주/매월 자동 갱신(Daily brief·Weekly review·Monthly snapshot)까지 원하면 **Cowork + Scheduled**(Pro 전용). 본인 루틴에 맞춘 작업 명세는 `appendix-pro/scheduled-jobs.md` 참고. 본편(무료)은 다운로드→로컬 누적까지로 완결입니다.
