# 내 결과물 4종 명세 — 본인 케이스

> 단계 4 "결과물 만들기"에서 만들 본인 결과물 4종의 형식·톤·완성 기준. 같은 Chat Project [파일] 영역의 02 산출물을 참고해 본 명세대로 결과물을 우측 Artifact 패널에 띄웁니다. 직무별로 자주 만드는 결과물이 다르니, 본인이 자주 만드는 것 위주로 1번(대표) + 옵션 3종을 갈아끼우세요.

## 1. 본인 1순위 결과물 (대표) — ✏️ 갈아끼우기

- **형식**: [예: HTML/SVG 정사각형 카드 / PDF 1페이지 / 마크다운 슬라이드 / 영업 제안서 1페이지]
- **헤더**: [예: "[가명] 2026 Q2 분기 회고"]
- **핵심 숫자 3개**: [본인이 가장 강조하고 싶은 KPI 3개]
- **부가**: [인사이트 1줄 + 다음 액션 1줄 + 워터마크]
- **스타일**: [다크 톤 + 브랜드 컬러 / 라이트 톤 + 정장 / 친근 톤 + 일러스트]
- **출력**: 우측 Artifact 패널

### 변주 — 동료/외부 공유 톤
[같은 데이터, 친근한 톤, 이모지 3개, 슬랙 공유용 카드 등]

## 2. 본인 2순위 결과물 — ✏️ 갈아끼우기

- **시점**: [예: 매주 금요일 / 매월 1일 / 매 분기 종료 직후]
- **형식**: [PDF 1페이지 / 마크다운 1페이지 / 슬라이드 5장]
- **구성**:
  1. [진행 현황]
  2. [지표 변동]
  3. [다음 기간 할 일 3개]
  4. [위험 1개 + 대응]

## 3. 본인 3순위 결과물 — ✏️ 갈아끼우기

직군별 예시:
- 영업: 영업 제안서 1페이지 시리즈 (도입·차별점·견적 톤 통일)
- 개발: 릴리즈 노트 시리즈 (사용자용·내부용 톤 분리)
- 기획: 신기능 안내 카드 시리즈 (런칭·중간·마감)
- HR: 채용 공고 카드 시리즈 (포지션·성장·복지)

## 4. 본인 4순위 결과물 — ✏️ 갈아끼우기

직군별 예시:
- 공통: 회의록 요약 PT (Marp 마크다운 → 5장)
- 영업: 분기 영업 전략 1분 영상 시나리오
- 개발: 신기능 데모 영상 시나리오
- 기획: 사용자 인터뷰 결과 요약 PT
- HR: 신규 정책 안내 5장 슬라이드

## 결과물 검증 체크리스트 (AI 출력 후 자동 확인)

- [ ] 실제 마감·금액·KPI 숫자가 02-work-data-template과 일치하는가
- [ ] 민감 정보(고객명·실제 KPI·계좌)가 포함되지 않았는가
- [ ] AI가 사실을 지어내지 않았는가 (출처 없는 숫자는 "추정" 표시)
- [ ] 외부 발송·임원 보고 전 사람 검토 필요한 부분이 명시되어 있는가
