# 단계 5 마케터 점검판 — 비주얼·인터랙션·6 위젯·Scheduled

## 비주얼 (필수)

- 배경: 다크 `#0E1620` 베이스 + **좌상단에서 퍼지는 녹색 글로우** (radial-gradient `rgba(105,219,124,0.18)`)
- 헤더 라인:
  - 좌측: "**김민지씨의 5월 점검판** · 캠페인·KPI·생활 통합"
  - 우측 상단: 노란 배지 ⭐ **오늘의 완성**
- 6 위젯 **3×2 그리드** (gap 16px)
  - 카드 배경 `#1B2330`, 외곽선 `rgba(105,219,124,0.55)`, 라운드 14px, 내부 18px padding
  - 위젯 헤더는 작은 번호 박스(1·2·3·4·5·6) + 한 줄 타이틀
- 폰트: Pretendard / 시스템 sans-serif, 헤더 18~22px, 본문 13~14px
- 호버 시 카드 외곽선이 살짝 밝아짐 (transition 0.2s)

## 인터랙션 (DB 없이 로컬 상태 — vanilla JS)

다음 인터랙션을 페이지 로드 시 즉시 동작하게 합니다. 초기 데이터는 명세대로 하드코딩.

| # | 인터랙션 | 동작 |
|---|----------|------|
| 1 | 투두 체크박스 토글 | 클릭 → 줄긋기 + 체크표시, 페이지 상태 유지 |
| 2 | 투두 "+ 할 일 추가" | 버튼 클릭 → 인라인 인풋 + Enter로 새 행 추가 |
| 3 | 캘린더 날짜 클릭 | 우측 슬라이드 패널에 그날 일정 표시 (제목·시간·메모) |
| 4 | 캘린더 "+ 일정 추가" | 선택 날짜 패널 안 폼 → 점 색·텍스트 등록 |
| 5 | KPI 게이지 호버 | 정확 수치 툴팁 표시 |
| 6 | 변동 지출 입력 | 인풋 입력 → 도넛 차트 즉시 갱신 + 합계 라인 갱신 |
| 7 | "오늘의 완성" 배지 | 위젯 6개 중 4개에 한 번 이상 클릭하면 활성화 (트로피 컬러) |

> **로컬 상태만** — 새로고침 시 초기 데이터로 복원. (실데이터 영속성은 5-2 단계에서 로컬 파일 연동으로 확장)

## Scheduled 작업 (Cowork → Scheduled)

대시보드만 만들어 두면 끝이 아니라, **Cowork 좌측 사이드바 Scheduled** 메뉴로 매일·매주 자동 갱신을 걸어 둡니다.

### Daily brief — 매일 09:00
```
/schedule daily 09:00
이 폴더 안 자료를 참고해서, 오늘 챙길 일 3가지를 요약해줘.
1) 오늘 D-day 캠페인 1건
2) 오늘 마감 임박 청약/세금/연차 1건 (03-search-results 참고)
3) 어제 SNS 발행 상태 갱신 (캘린더 위젯 2 동기화)
```

### Weekly review — 매주 금요일 18:00
```
/schedule weekly fri 18:00
이번 주 캠페인 KPI 변동치를 02-campaign-analysis 기준 대비 정리하고,
다음 주 인포그래픽 카드 1장 초안(04-deliverable-brief 1번 명세 사용)을 만들어 결과물 패널에 띄워.
```

### Monthly snapshot — 매월 1일 09:00
```
/schedule monthly 1 09:00
지난달 점검판 6 위젯 스냅샷을 PDF로 저장하고,
이번 달 시작 헤더 부제를 갱신해줘 ("내 {YYYY-MM} 점검판").
```

## 완료 기준

- ☐ 위젯 6개 중 4개 이상 화면 표시
- ☐ 변동 지출 1개 이상 입력 → 화면 갱신
- ☐ 투두 1개 이상 체크 → 시각 반응
- ☐ Scheduled 작업 1개 이상 등록 (Pro 이상)
