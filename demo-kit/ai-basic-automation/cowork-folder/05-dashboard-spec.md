# 단계 5 마케터 점검판 — 6 위젯 + Scheduled

> 단계 5 "나만의 대시보드 만들기"의 통합 화면 명세. AI는 같은 폴더의 01~04 산출물을 모두 참고해 단일 HTML 한 페이지로 결과물 패널에 띄웁니다.

## 통합 원칙

- 단일 HTML 한 페이지에 6 위젯
- 데이터는 01·02·02-spending·03·04 파일에서 자동 추출 (사용자 입력 0)
- Cowork **Live Artifacts ON** 권장 — 새로고침 뒤에도 입력·체크 상태 유지

## 헤더

- 제목: "내 5월 점검판"
- 부제: "캠페인 · KPI · 생활 통합"
- 우측 상단: ⭐ 오늘의 완성 배지

## 6 위젯 (좌측·중앙·우측 × 상단·하단)

### 위젯 1 — 캠페인 진행 (좌상단)
- 출처: 02-campaign-analysis.md
- 행: 봄 신상 "Hello May" / RUN / 종료 D+1 · 충성고객 리텐션 메일 / RUN / D+5 · 인플루언서 협업 / PLAN / D-14
- 각 행: 캠페인명 · 상태 · D-day

### 위젯 2 — SNS 콘텐츠 캘린더 (중상단)
- 출처: 04-deliverable-brief.md "SNS 카드 3장 시리즈" + 회사 SNS 캘린더
- 5월 셋째 주 (월~금) 5행: 날짜 · 플랫폼 · 콘텐츠 제목 · 상태(초안/검수/발행)

### 위젯 3 — KPI 트래커 (우상단)
- 출처: 02-campaign-analysis.md "핵심 KPI 3 (목표 vs 실적)"
- 진행 바: CTR 84% / CPC 88% / 전환율 113% / ROAS 115%

### 위젯 4 — 고정 지출 + 변동 입력 (좌하단)
- 출처: 02-spending-summary.md "공과금" + 알려진 고정비
- 표: 월세 80만(1일) · 관리비 12만(5일) · 전기 4.5만(10일) · 가스 1.9만(10일) · 건보 18만(10일) · 적금 30만(25일)
- 변동 입력 3칸: 이번 달 전기·가스·건보 추가 입력 (localStorage 저장)

### 위젯 5 — 오늘의 루틴 (중하단)
- 출처: 01-quarter-checklist.md "이번 주 첫 행동" + 회의록
- 체크박스 5개: 회의록 정리 · 고객 답장 5건 · 주간 보고서 초안 · SNS 릴스 초안(수) · 운동 30분

### 위젯 6 — 통합 캘린더 (우하단)
- 출처: 03-search-results.md "다음 액션 (캘린더 옮기기)" + 고정비 결제일
- 5월 7×5 그리드. 노란 점=결제일(1·5·10·12·25), 파란 점=캠페인(20·28), 초록 점=세미나/세금(20·24·28·30)

## 스타일

- 다크 (#1D242B) + 블루 글로우 (#068FFF), 카드 #252E37, 옐로우 #FFD166, 그린 #69DB7C
- Pretendard / 시스템 sans-serif
- 위젯 6개를 3×2 그리드, 위젯 간 12~16px gap, 카드 모서리 14px

## Scheduled 작업 (Cowork → Scheduled)

대시보드만 만들어 두면 끝이 아니라, **Cowork 좌측 사이드바 Scheduled** 메뉴로 매일·매주 자동 갱신을 걸어 둡니다.

### Daily brief — 매일 09:00
```
/schedule daily 09:00
이 폴더 안 자료를 참고해서, 오늘 챙길 일 3가지를 요약해줘.
1) 오늘 D-day 캠페인 1건
2) 오늘 마감 임박 청약/세금/연차 1건 (03-search-results 참고)
3) 어제 SNS 발행 상태 갱신 (캘린더 위젯 2 동기화)
```

### Weekly review — 매주 금요일 18:00
```
/schedule weekly fri 18:00
이번 주 캠페인 KPI 변동치를 02-campaign-analysis 기준 대비 정리하고,
다음 주 인포그래픽 카드 1장 초안(04-deliverable-brief 1번 명세 사용)을 만들어 결과물 패널에 띄워.
```

### Monthly snapshot — 매월 1일 09:00
```
/schedule monthly 1 09:00
지난달 점검판 6 위젯 스냅샷을 PDF로 저장하고,
이번 달 시작 헤더 부제를 갱신해줘 ("내 {YYYY-MM} 점검판").
```

## 완료 기준

- ☐ 위젯 6개 중 4개 이상 화면 표시
- ☐ 변동 지출 1개 이상 입력 → 화면 갱신
- ☐ 투두 1개 이상 체크 → 시각 반응
- ☐ Scheduled 작업 1개 이상 등록 (Pro 이상)
