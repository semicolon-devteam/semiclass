# CLAUDE.md — 폴더 자동 컨텍스트

> 이 파일은 Cowork이 폴더를 열 때 **자동으로 가장 먼저 읽는** 지침 파일입니다. Chat 모드의 Project "지침(Instructions)"과 같은 역할을 폴더 단위로 합니다. 사용자가 별도로 "이 파일을 참고해 줘"라고 말하지 않아도 모든 응답이 이 컨텍스트 위에서 시작합니다.

## 이 폴더가 무엇인지

SemiClass 비정기 클래스 **"AI 쉽고 재밌게 활용하기: 기초편"** 의 실습 4·5 데모용 자료실입니다. 단계 0의 페르소나 지침과 단계 1~3에서 만든 산출물이 모두 이 폴더 안에 들어 있어, Cowork으로 폴더 연결만 하면 단계 4의 결과물 만들기와 단계 5의 통합 대시보드까지 한 번에 이어집니다.

폴더 안 다른 파일들:

- `00-내-프로필.md` — 사용자 페르소나 상세 (이 파일과 일부 중복, 사람이 보기 좋은 사본)
- `01-quarter-checklist.md` — 단계 1 산출물 (분기 체크리스트)
- `02-campaign-analysis.md` — 단계 2 산출물 (5월 캠페인 분석)
- `02-spending-summary.md` — 단계 2 옵션 (카드·고지서 분석)
- `03-search-results.md` — 단계 3 산출물 (청약·세금·연차 검색 결과)
- `04-deliverable-brief.md` — 결과물 4종 명세
- `05-dashboard-spec.md` — 6 위젯 대시보드 + Scheduled 명세

## 사용자 페르소나 — 항상 적용

- 서울 마포 1인가구, 고양이 치즈 한 마리
- 청약·적금·CMA 관리 중, 청년 우대형 가입 아직
- 헬스장 두 달째 안 감, 작년 검진에서 콜레스테롤 살짝 높음

> **본인 변주**: 위 첫 두 줄(직무·가구)만 본인에 맞게 바꾸면 모든 결과물에 자동 반영됩니다.

## 답변 톤·정책

- 답변은 늘 **한국어 친근체**로 (반말이 자연스러운 일상 영역) 또는 정돈된 존댓말(임원 보고·외부 발송)을 맥락에 맞게
- 숫자에 출처가 없으면 **"추정"** 표시
- 민감정보(고객명·실제 KPI·계좌)는 가명·둥근 숫자로 바꿔서 처리
- 외부 발송·임원 보고용 결과는 **"사람 검토 필요"** 표시
- 사용자가 "나에 대해 말해봐" 등 자기 소개를 요청하면, 위 페르소나 정보를 기반으로 한 줄 요약
