# Cowork 임포트 폴더 — 내 사령탑 자료실

이 폴더 안의 파일을 Claude **Cowork 모드 → 새 작업 → 폴더 연결**에서 통째로 지정하면, 단계 4~5에서 AI가 모든 자료를 즉시 참조합니다. 단계 1~3에서 만든 결과물(체크리스트·캠페인 분석·검색 결과)이 함께 들어 있어, 단계 4의 결과물 만들기와 단계 5의 통합 대시보드까지 한 번에 이어집니다.

## 폴더 구성

```
cowork-folder/
├── README.md                       (이 파일 — AI가 컨텍스트로 읽음)
├── 01-quarter-checklist.md         (단계 1 산출물 가정 — 분기 체크리스트)
├── 02-campaign-analysis.md         (단계 2 산출물 가정 — 캠페인 5월 분석 + 개선 5종)
├── 02-spending-summary.md          (단계 2 산출물 가정 — 카드·고지서 분석)
├── 03-search-results.md            (단계 3 산출물 가정 — 청약·세금·연차 검색 결과)
├── 04-deliverable-brief.md         (단계 4 결과물 4종 가이드)
└── 05-dashboard-spec.md            (단계 5 6 위젯 대시보드 명세)
```

## 사용 흐름

### 단계 4 (결과물 만들기)
"`/cowork-folder/`의 자료들 활용해서 5월 캠페인 인포그래픽 카드 1장 만들어줘." 정도면 AI가 02·04 파일을 자동 참고합니다.

### 단계 5 (통합 대시보드)
"`/cowork-folder/` 전체 자료를 활용해 마케터 5월 점검판 대시보드를 만들어줘. 05-dashboard-spec.md 명세를 따라줘." 라고 하면 1~4 산출물이 한 화면에 모입니다.

### Scheduled 작업 (Cowork → Scheduled)
Cowork 좌측 사이드바 **Scheduled** 메뉴에서:
- **Daily brief**: 매일 아침 9시, 단계 3 검색 결과를 갱신하고 단계 5 대시보드의 "오늘의 정보" 위젯에 반영
- **Weekly review**: 매주 금요일 18시, 단계 2 캠페인 KPI 변동을 요약해서 다음 주 액션 1줄로 정리

```
/schedule daily 09:00 — 어제 캠페인 KPI 변동치 정리 + 오늘 챙길 청약/세금 일정 1줄
/schedule weekly fri 18:00 — 이번 주 SNS 콘텐츠 발행 상태 점검 + 다음 주 인포그래픽 1장 초안
```

## AI에게 한 줄 안내

> 사용자(33세 1인가구 마케터)가 단계 1~3에서 만든 산출물과 단계 4·5 명세가 이 폴더에 모여 있습니다. 사용자가 "결과물 만들어줘"라고 하면 02·04 파일을 참고하고, "대시보드 만들어줘"라고 하면 01~05 전체를 통합해서 6 위젯 화면을 우측 결과물 패널에 띄워주세요.
