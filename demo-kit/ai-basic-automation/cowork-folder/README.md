# Cowork 임포트 폴더 — 내 사령탑 자료실

이 폴더 안의 파일을 Claude **Cowork 모드 → 새 작업 → 폴더 연결**에서 통째로 지정하면, 단계 4~5에서 AI가 모든 자료를 즉시 참조합니다. 단계 0의 페르소나·지침부터 단계 1~3에서 만든 산출물(체크리스트·캠페인 분석·검색 결과)까지 함께 들어 있어, Chat의 Project 지침을 자동 가져오지 않는 Cowork에서도 같은 컨텍스트로 이어집니다.

## 폴더 구성 (정리 전 — 데모 시작 상태)

```
cowork-folder/
├── CLAUDE.md                       ⭐ 폴더 열 때 Cowork이 자동으로 먼저 읽는 지침
├── README.md                       (사람용 폴더 안내)
├── 00-내-프로필.md                  (페르소나 사람용 사본 — CLAUDE.md와 일부 중복)
├── 01-quarter-checklist.md         (단계 1 산출물 — 분기 체크리스트)
├── 02-campaign-analysis.md         (단계 2 산출물 — 5월 캠페인 분석 + 개선 5종)
├── 02-spending-summary.md          (단계 2 옵션 — 카드·고지서 분석)
├── 03-search-results.md            (단계 3 산출물 — 청약·세금·연차 검색 결과)
├── 04-deliverable-brief.md         (단계 4 결과물 4종 명세)
└── 05-dashboard-spec.md            (단계 5 6 위젯 + Scheduled 명세)
```

> **왜 `CLAUDE.md`?** Cowork은 Chat 모드의 Project 지침을 자동으로 가져오지 않습니다. 대신 폴더 최상위의 `CLAUDE.md`를 폴더 열 때 가장 먼저 읽어 컨텍스트로 사용합니다. 페르소나·답변 톤·자주 쓰는 결과물 명세를 여기 두면 모든 응답이 그 위에서 시작합니다.
>
> 같은 효과를 **Cowork UI의 "폴더 지침" 다이얼로그**(폴더 우측 ⋯ → 폴더 지침)에서 직접 입력해서 낼 수도 있어요 — Chat의 지침 입력과 거의 같은 UX입니다. 둘 다 쓰면 CLAUDE.md → 폴더 지침 순으로 같이 적용됩니다.

## 정리하기 (실습 4 시작 직전 1~2분 데모)

평평하게 펼쳐진 영문 파일명은 학생이 다음 회차에 본인 자료로 갈아끼울 때 한눈에 안 들어옵니다. AI에게 정리도 맡길 수 있어요.

**프롬프트 — 폴더 정리 요청**

```text
이 폴더 안의 파일들을 보기 좋게 정리해줘.

- "데이터"와 "결과물 명세"를 폴더로 분리해줘 (예: 1-원본데이터/, 2-산출물/, 3-결과물-명세/)
- 영문 파일명을 알아보기 쉬운 한글로 바꿔줘 (00-내-프로필.md는 그대로 유지)
- 어디로 옮겼는지 옮긴 후 폴더 구조를 트리로 보여줘
- 옮긴 뒤 모든 파일이 AI에게 같은 컨텍스트로 잘 읽히는지 한 줄로 확인해줘
```

**정리 후 폴더 구조 (예시)**

```
cowork-folder/
├── CLAUDE.md                       ⭐ 그대로 유지 (자동 지침)
├── 00-내-프로필.md
├── 1-원본데이터/
│   └── 분기-체크리스트.md          (← 01-quarter-checklist)
├── 2-산출물/
│   ├── 캠페인-5월-분석.md          (← 02-campaign-analysis)
│   ├── 지출-요약.md                (← 02-spending-summary)
│   └── 검색-결과-청약세금연차.md   (← 03-search-results)
└── 3-결과물-명세/
    ├── 결과물-4종-가이드.md        (← 04-deliverable-brief)
    └── 점검판-대시보드-스펙.md     (← 05-dashboard-spec)
```

> 정리 프롬프트에 "CLAUDE.md는 폴더 최상위 그대로 유지"를 한 줄 더 적어 두면 AI가 안전하게 옮깁니다.

> 정리된 폴더는 그대로 두면 다음 회차·다음 분기에도 같은 구조 그대로 쓸 수 있어요. AI는 어느 위치에서든 파일명·내용으로 알아서 찾아 참조합니다.

## 사용 흐름

### 단계 4 (결과물 만들기)
"`/cowork-folder/`의 자료들 활용해서 5월 캠페인 인포그래픽 카드 1장 만들어줘." 정도면 AI가 02·04 파일을 자동 참고합니다.

### 단계 5 (통합 대시보드)
"`/cowork-folder/` 전체 자료를 활용해 마케터 5월 점검판 대시보드를 만들어줘. 05-dashboard-spec.md 명세를 따라줘." 라고 하면 1~4 산출물이 한 화면에 모입니다.

### Scheduled 작업 (Cowork → Scheduled)
Cowork 좌측 사이드바 **Scheduled** 메뉴에서:
- **Daily brief**: 매일 아침 9시, 단계 3 검색 결과를 갱신하고 단계 5 대시보드의 "오늘의 정보" 위젯에 반영
- **Weekly review**: 매주 금요일 18시, 단계 2 캠페인 KPI 변동을 요약해서 다음 주 액션 1줄로 정리

```
/schedule daily 09:00 — 어제 캠페인 KPI 변동치 정리 + 오늘 챙길 청약/세금 일정 1줄
/schedule weekly fri 18:00 — 이번 주 SNS 콘텐츠 발행 상태 점검 + 다음 주 인포그래픽 1장 초안
```

## AI에게 한 줄 안내

> 사용자(33세 1인가구 마케터)가 단계 1~3에서 만든 산출물과 단계 4·5 명세가 이 폴더에 모여 있습니다. 사용자가 "결과물 만들어줘"라고 하면 02·04 파일을 참고하고, "대시보드 만들어줘"라고 하면 01~05 전체를 통합해서 6 위젯 화면을 우측 결과물 패널에 띄워주세요.
