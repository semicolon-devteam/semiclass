# Claude Design 프롬프트: 디자인 룬

아래 프롬프트를 Claude Design에 붙여 넣고, 결과를 `.semiclass/artifacts/design-rules.md`로 저장합니다.

```text
바이브코딩 클래스 데모에서 사용할 "우리동네 공공데이터 생활정보 보드"의 첫 화면 디자인 기준을 만들고 싶어.

입력으로는 service-spec.md를 사용할 거야. 서비스는 주변 생활정보를 카드 목록으로 보여주고, 검색/필터와 관심 저장 버튼이 있는 실무형 웹앱이야.

목표:
- 비전공자도 사용법을 바로 이해하는 화면
- 직장인이 실제로 쓸 수 있는 조용하고 실무적인 톤
- SemiClass 톤의 어두운 배경과 파란 포인트 컬러
- 모바일에서도 카드 목록과 저장 버튼이 잘 보이는 구조
- 이후 Claude Code가 바로 구현할 수 있는 명확한 기준

결과 형식은 design-rules.md 형태로 정리해줘.

아래 섹션 제목을 그대로 사용해줘.

## 톤
## 색상 토큰
## 타이포
## 레이아웃 규칙
## 컴포넌트 규칙
## 첫 화면 와이어프레임
## 모바일 규칙
## Claude Code 구현 지시문
## 디자인 확인 체크리스트

컴포넌트 규칙에는 검색 입력, 카테고리 필터, 생활정보 카드, 저장 버튼, 상세 패널, 빈 상태를 포함해줘.

와이어프레임은 텍스트 기반으로 작성해줘. 이후 Claude Code가 `app/page.tsx`와 CSS를 만들 때 그대로 참고할 수 있어야 해.
```
