# Manyfast 프롬프트: 기획의 나침반

아래 프롬프트를 Manyfast에 붙여 넣고, 결과를 `.semiclass/artifacts/service-spec.md`로 저장합니다.

```text
바이브코딩 클래스 데모의 첫 기획 산출물을 만들고 싶어.

만들고 싶은 서비스는 "우리동네 공공데이터 생활정보 보드"야. 사용자가 주변 생활정보를 카드로 보고, 검색/필터하고, 마음에 드는 항목을 저장하는 웹서비스를 만들고 싶어.

먼저 내가 답하기 쉬운 질문을 해줘. 질문은 아래 항목을 빠짐없이 확인하는 순서로 구성해줘.

- 사용자는 누구인지
- 사용자가 처음 들어와서 무엇을 해야 하는지
- 꼭 필요한 기능 3개
- 나중에 넣어도 되는 기능 3개
- 어떤 데이터가 필요한지
- 저장해야 하는 데이터와 저장하지 않아도 되는 데이터
- 모바일에서 가장 중요한 화면
- 오늘 수업 안에 완료했다고 판단할 기준

내 답변을 받은 뒤에는 service-spec.md 형태로 정리해줘.

결과 형식은 아래 섹션 제목을 그대로 사용해줘.

## 사용자
## 처음 흐름
## 핵심 기능 3개
## 나중 기능 3개
## 데이터
## 저장 정책
## 모바일 핵심 화면
## 오늘 완료 기준
## Claude Code 구현 체크리스트

마지막에는 "다음 단계로 넘겨도 되는지" 확인할 수 있는 짧은 체크리스트도 붙여줘.
```
