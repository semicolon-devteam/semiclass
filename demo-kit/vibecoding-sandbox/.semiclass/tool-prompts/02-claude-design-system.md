# Claude Design 프롬프트: 디자인 시스템

아래 프롬프트를 Claude Design에 붙여 넣고, 결과를 `.semiclass/artifacts/design-system.md`로 저장합니다.

```text
바이브코딩 클래스 데모에서 사용할 "우리동네 공공데이터 생활정보 보드"의 디자인 시스템을 만들고 싶어.

이 단계의 목표는 화면을 바로 만드는 것이 아니라, 이후 프로토타입과 Claude Code 구현이 흔들리지 않도록 공통 디자인 기준을 먼저 정하는 거야.

서비스 맥락:
- 주변 생활정보를 카드 목록으로 보여주는 실무형 웹앱
- 검색, 카테고리 필터, 관심 저장 버튼, 상세 패널이 있는 구조
- 비전공자도 바로 이해할 수 있어야 함
- 직장인이 실제로 쓸 수 있는 조용하고 실무적인 톤
- SemiClass 톤의 어두운 배경과 파란 포인트 컬러

결과는 design-system.md 형태로 정리해줘.

아래 섹션 제목을 그대로 사용해줘.

## 디자인 원칙
## 색상 토큰
## 타이포 토큰
## 간격과 라운드 토큰
## 버튼 규칙
## 입력과 필터 규칙
## 카드 규칙
## 상세 패널 규칙
## 상태 표현 규칙
## 모바일 기본 규칙
## Claude Code 구현 메모

각 규칙은 추상적인 설명만 하지 말고, 실제 CSS 변수나 컴포넌트 구현에 옮길 수 있을 정도로 구체적으로 써줘.

마지막에는 "이 디자인 시스템을 다음 프로토타입 단계로 넘겨도 되는지" 확인할 체크리스트를 붙여줘.
```
