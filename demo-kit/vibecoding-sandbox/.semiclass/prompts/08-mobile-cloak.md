# 프롬프트 7: 모바일 망토

```text
생활정보 보드를 모바일에서도 편하게 쓰고, 푸시 알림 데모까지 볼 수 있도록 다듬어줘.

요구사항:
- 기존 CSS를 Tailwind CSS 중심으로 정리해.
- 작은 화면에서는 목록과 상세 패널이 세로로 쌓이게 해.
- 버튼 터치 영역을 충분히 크게 해.
- 검색/필터/저장 버튼이 화면 밖으로 밀리지 않게 해.
- manifest.webmanifest와 아이콘을 추가해 홈 화면에 앱처럼 추가할 수 있게 해.
- Firebase Cloud Messaging 연동 예시를 추가해.
- service worker, VAPID key env, 알림 권한 요청 버튼, 데모 알림 전송 흐름을 준비해.
- 브라우저 권한이나 실기기 제약이 있을 때 사용할 mock send 경로와 리허설 체크리스트를 알려줘.
```
