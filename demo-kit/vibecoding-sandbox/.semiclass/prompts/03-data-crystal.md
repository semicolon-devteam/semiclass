# 프롬프트 2: 데이터 크리스탈

```text
방금 만든 생활정보 보드에 공공데이터를 연결할 준비를 해줘.

요구사항:
- 화면 코드 안에 박힌 샘플 데이터를 public/sample-public-data.json으로 분리해줘.
- 나중에 실제 공공데이터 API로 바꿀 수 있도록 fetchPublicItems() 함수를 분리해줘.
- 화면 컴포넌트는 데이터가 어디서 오는지 몰라도 동작하게 만들어줘.
- 데이터가 비어 있을 때 보여줄 empty state도 추가해줘.

이번 단계 범위:
- 샘플 JSON만으로 안정적으로 동작하게 해줘.
- 실제 API로 교체할 위치와 env 이름을 주석 또는 README에 정리해줘.
```
